# 🚀 Backend API Teste Startali

## 📋 Sobre o Projeto

Bem-vindo ao **Backend API Teste Startali**! Este projeto é uma API robusta e bem estruturada desenvolvida para para o teste de uma aplicação web.

## ✨ Características

- 🔐 Autenticação segura
- 📊 Endpoints RESTful
- 🗄️ Integração com banco de dados
- 🧪 Testes automatizados
- 📝 Documentação completa

## 🛠️ Tecnologias

- **Node.js**
- **Express**
- **SQLite**
- **Jest**

## 📦 Instalação

```bash
git clone <seu-repositorio>
cd backend-api-teste-startali
npm i --legacy-peer-deps
```

## ▶️ Como Executar

```bash
npm start
```

## 🧪 Testes

```bash
npm test
```
